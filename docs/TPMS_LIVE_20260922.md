## Reproduction and protection against regressions

`firmware/tests/fixtures/TPMS_LIVE_20260922.jsonl` preserves all 32 frame
records and all five reference events verbatim as JSON objects, including
host timestamps, firmware receive times, raw payloads and original serial
lines. `TPMS_LIVE_20260922.pulses.txt` preserves all 13 raw pulse dumps.
Startup binary noise, package metadata and unrelated port details are not
part of these narrowly scoped fixtures; the original ZIP is unchanged.

```sh
python3 firmware/tools/tpms_calibration.py session.zip --out new-report.json
python3 firmware/tests/run_replay.py
```

The offline tool needs only Python's standard library, does not open a COM
port, and refuses to overwrite its input or an existing output. It rebuilds
the report from original events, not the old derived calibration report.
Regression tests cover delayed entries, duplicate and conflicting references,
clock changes, mixed sensors, unconfirmed transitions, future-only frames,
the exact uploaded session, outliers and raw serial preservation.

Live capture now prints association quality, duplicate detection and distinct
observation/value counts after every entry. Fitting still requires at least
four independent observations and three distinct reference values for each
quantity, tests every independent point and leave-one-observation-out errors,
and keeps delayed-association models separate for review. Candidate fitting
never publishes units to firmware automatically.

## Continue without discarding these points

The kit includes the recorded frame/reference fixture as
`calibration-baseline.jsonl`, protected by the package manifest hashes.
`Test-TPMS.ps1 -ResumeCalibration` starts live capture using that evidence as
a baseline. New entries still require new RF in the current session. Each
session is associated independently before fitting the combined points, so
restarted host clocks cannot bind a new entry to old RF. The new session ZIP
includes the exact baseline JSONL and can be reanalyzed on its own. Baseline
associations retain their delayed-candidate status and unverified mappings.
At least two more independent observations, with at least three distinct
values per quantity overall, are needed to reach the candidate-fit gate;
passing that count alone does not validate a formula.
