# اختبار TPMS واحد — النسخة الحالية

هذه النسخة تفك الإطار الحقيقي وتتحقق من Manchester وSUM8 وتكراره.
**الضغط والحرارة ومعرّف الحساس النهائي لم تثبت خرائطها بعد**؛ تظهر
`null`، ويظهر `15B99AA4` كمعرّف مرشح فقط في الالتقاطات السابقة.

## التشغيل

1. نزّل artifact باسم **DarbakVehicleHub-ESP32-TPMS** من بناء GitHub Actions
   المشار إليه، وفك ZIP كاملًا إلى مجلد واحد.
2. صِل ESP32 نفسه عبر USB وأغلق أي Serial Monitor. احتفظ بتوصيل CC1101 الحالي.
3. افتح PowerShell داخل المجلد، ثم نفذ:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Test-TPMS.ps1
```

الأمر يجهز أدوات Python في بيئة مستقلة، يحدد منفذ ESP32 إذا كان واضحًا،
يتحقق من ملفات الحزمة، يفلش التطبيق عند **0x10000** ثم يبدأ التقاطًا واحدًا.
يلزم Python 3 واتصال إنترنت لتنزيل الأدوات. عند وجود منافذ متعددة سيطلب
المنفذ فقط؛ يمكن تحديده مسبقًا بإضافة `-Port COM3`.

الحزمة مخصصة للجهاز الموجود عليه firmware المشروع بالفعل، وبنفس جدول
الأقسام. لا تمسح كامل الفلاش ولا تكتب ملف التطبيق عند 0x0000.
ملفا bootloader وpartitions مرفقان للتشخيص، ولا يكتبهما الاختبار.

## الجلسة الواحدة

اضبط شاشة TPMS الأصلية على **PSI و°C** واستخدم **الحساس نفسه** في المراحل الثلاث:

| المرحلة | ما تفعله | ما تدخله |
|---|---|---|
| 1 | فك الحساس من البلف واتركه قرب CC1101 بدرجة الجو | ضغط وحرارة جديدان من الشاشة الأصلية |
| 2 | ركبه طبيعيًا على بلف الكفر وانتظر تحديث الشاشة | ضغط وحرارة جديدان |
| 3 | فكه وأمسك جسمه في يدك نحو دقيقة حتى تتغير حرارة الشاشة، ويفضل درجتين | ضغط وحرارة جديدان |

أدخل العددين في سطر مثل `33.5 28`، أو `-` إذا لم تتحدث الشاشة.
**المثال صيغة إدخال فقط، وليس قراءة من جهازك.** التسجيل مستمر أثناء تنفيذ
الخطوات والكتابة، ويحفظ حتى المخرجات غير المفكوكة. لا تُنقص هواء الكفر
للتجربة؛ تُستخدم حالة الحساس المفكوك كنقطة الضغط الجوي.

كل مرحلة تنتظر تكرارًا صالحًا حتى 75 ثانية إذا لم يصل مسبقًا.
لا تعيد التجربة عند غياب إحدى القراءات: أرسل الناتج نفسه، بما فيه حالة
عدم الاستقبال أو عدم تغير الحرارة. أعد تركيب الحساس طبيعيًا بعد النهاية.

ارفع **ملف ZIP واحدًا** يبدأ اسمه بـ `TPMS_ONE_TEST_`. يتضمن البيانات
والقراءات المرجعية والتوقيت وبصمة البناء، ولا يملأ قيمًا افتراضية.

## الالتقاط اليدوي عند الحاجة فقط

من المستودع، دون تفليش:

```powershell
py firmware/tools/tpms_capture.py --port COM3 --seconds 180
```

للتشغيل التفاعلي من الحزمة دون إعادة التفليش استخدم `-SkipFlash`.
هذا ليس اختبارًا إضافيًا مطلوبًا.

## التوصيل الموجود

| CC1101 | ESP32 |
|---|---|
| VCC | 3.3V |
| GND | GND |
| SCK | GPIO18 |
| MISO | GPIO19 |
| MOSI | GPIO23 |
| CSN | GPIO5 |
| GDO0 | GPIO4 |
| GDO2 | GPIO2 |

التردد 433.92 MHz. لا يستخدم RSSI بعد burst لقبول الإطار أو رفضه.
التفاصيل والأدلة: [TPMS_DECODER.md](TPMS_DECODER.md).
